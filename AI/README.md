# AI Assistant

A simple AI assistant with voice recognition and GUI interface that can perform basic tasks like opening Google, YouTube, and system applications.

## Features

- Voice recognition for commands
- Text-to-speech responses
- GUI interface with conversation history
- Can open:
  - Google
  - YouTube
  - Notepad
  - Calculator
- Basic conversation capabilities

## Requirements

- Python 3.7 or higher
- Microphone
- Internet connection (for voice recognition)

## Installation

1. Clone this repository or download the files
2. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage

1. Run the AI assistant:
   ```
   python ai_assistant.py
   ```
2. Click the "Start Voice Input" button to begin voice recognition
3. Speak your command clearly
4. The assistant will respond and perform the requested action

## Available Commands

- "Open Google" - Opens Google in your default browser
- "Open YouTube" - Opens YouTube in your default browser
- "Open Notepad" - Opens Windows Notepad
- "Open Calculator" - Opens Windows Calculator
- "Hello" or "Hi" - Basic conversation

## Note

Make sure your microphone is properly connected and configured before using the voice recognition feature.
